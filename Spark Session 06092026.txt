#Spark-Core

RDD : Resilient DIstributed Dataset
immutable in nature 
RDD divided into mutiple partitions


Partitions - 
imp parallel processing
it should not quite more or less
imp for optimization
Number of partitions depend on source
HDFS blocks=RDD partitions 
LFS = 2 partitions
Number of partitions= number of op files 


3 ways to create RDD :
#1.from collection (using parallelize)

ls=["Java","Scala","Python","R","Cpp"]

rdd=spark.sparkContext.parallelize(ls)

rdd.getNumPartitions()

rdd1=rdd.map(lambda x:x+" Programming")

rdd1.collect()

expected op:
op_ls=["Java Pragramming","Scala Pragramming","Python Pragramming","R Pragramming","Cpp Pragramming"]

#Operations on RDD***** 

1.Transformation
Operation on RDD and result we are getting new rdd - Transformation
exm- map,filter,reduceByKey,flatMap

rdd1=rdd.map(lambda x:x+" Partitions")

2.Action
Operation on RDD we are getting result as value or collection output - Action

exm - collect, getNumPartitions , saveAsTextFile , count , take(n)

#Word Count : 

input.txt
java is easy
python is easy
python is imp
python is free

rdd=spark.sparkContext.textFile("D:/tmp/input.txt")
rdd.collect()

['java is easy', 'python is easy', 'python is imp', 'python is free']

rdd1=rdd.flatMap(lambda x:x.split(" "))
rdd1.collect()

['java', 'is', 'easy', 'python', 'is', 'easy', 'python', 'is', 'imp', 'python', 'is', 'free']


rdd2=rdd1.map(lambda x:(x,1))
rdd2.collect

[('java', 1), ('is', 1), ('easy', 1), ('python', 1), ('is', 1), ('easy', 1), ('python', 1), ('is', 1), ('imp', 1), ('python', 1), ('is', 1), ('free', 1)]

rdd3=rdd2.reduceByKey(lambda x,y:x+y)
rdd3.collect()

[('java', 1), ('is', 4), ('python', 3), ('imp', 1), ('free', 1), ('easy', 2)]

rdd3.saveAsTextFile("D://wc_op")
('java', 1)
('is', 4)
('python', 3)
('imp', 1)
('free', 1)
('easy', 2)
